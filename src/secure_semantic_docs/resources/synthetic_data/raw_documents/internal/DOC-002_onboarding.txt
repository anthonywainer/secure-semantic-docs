ONBOARDING GUIDE FOR NEW DATA ENGINEERS
========================================
Department: Engineering | Classification: Internal

Welcome to the engineering team. This guide will help you get productive
in your first two weeks.

WEEK 1 - SETUP
- Install Python 3.12+, uv, and Docker Desktop.
- Clone the main repository and run `uv sync`.
- Complete your laptop security setup with IT (ticket PROJ-TEC-593).
- Read the Data Platform Engineering Handbook.

WEEK 2 - FIRST CONTRIBUTION
- Pick up a starter task from the backlog.
- Pair with a senior engineer for your first PR.
- Attend the weekly data platform sync on Wednesdays.

TOOLS
- Spark UI: http://localhost:4040 (when running locally)
- Chroma: http://localhost:8000
- OpenMetadata: http://localhost:8585
